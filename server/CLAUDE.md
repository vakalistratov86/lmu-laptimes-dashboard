# CLAUDE.md — server

## Контекст

Backend: парсинг логов LMU (logParser.ts), фоновая обработка импорта (importWorker.ts), API, доступ к БД.

## Правила

- logParser.ts — чистая функция (raw log) => ParsedSession, без записи в БД и без побочных эффектов
- importWorker.ts — единственное место, где парсер вызывается и результат пишется в БД
- Формат входных логов может отличаться между версиями игры — проверять версию/сигнатуру файла перед парсингом
- Неизвестные поля лога — не выбрасывать исключение, логировать warning, сохранять как raw JSON
- Все эндпоинты API возвращают формат { data, error }
- Валидация входных данных (zod/io-ts) обязательна до бизнес-логики
- Запросы к БД — только через repository-функции, не inline SQL в контроллерах

## Запреты

- Не изменять исходный лог-файл на диске
- Не логировать полные payload запросов с путями к файлам пользователя
- Не хранить бизнес-логику парсинга в API-контроллерах
