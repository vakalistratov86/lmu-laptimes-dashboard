# Правила клиента (дашборд)

- components/ — только отображение, без логики парсинга/доступа к БД
- Запросы к API — только через lib/, не прямой fetch в компонентах
- Графики — переиспользуемые компоненты, конфигурация через props
- Обязательна обработка состояний loading/error в компонентах с данными сессии
