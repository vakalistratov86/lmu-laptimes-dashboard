# CLAUDE.md — client

## Контекст
React-фронтенд дашборда: components, hooks, lib, pages.

## Правила
- components/ не содержат логику парсинга или прямого доступа к БД — только отображение данных из hooks/lib
- Запросы к серверу — только через lib/ (API-клиент), не прямые fetch внутри components
- Графики телеметрии — переиспользуемые компоненты с конфигурацией через props, без хардкода осей/цветов
- Состояние загрузки и ошибки обязательно обрабатывать в каждом компоненте, зависящем от данных сессии
- hooks/ инкапсулируют работу с данными (fetch, кэширование), не содержат JSX

## Запреты
- Не делать прямых обращений к server/ типам — использовать только типы из shared/
- Не хранить состояние сессии/кругов в глобальных переменных вне hooks
